# P3 科研判断（增强适配尚在训练）

已完成24次因果开发干预和80次独立基线评测；96000位置Joint LoRA实际训练进行中，最后20次评测未执行，不能给出最终训练不足判断。

A3获得8/8稳定接触抬升、5/8完整任务，A1为1/8、1/8，A2为0/8、0/8。标准物体相对位姿迁移、连续OSC与合适闭爪时序能恢复物理抓持，但A1固定原臂动作、没有标准抬升，不能把全部差异唯一归于静态位姿；A1/35偏离单一模板仍成功，模板也不是合法抓取全集Oracle。

40–59现有对照：UR5e原始Joint6/20，Panda原始Joint2/20，B1为1/20，旧6000样本Joint LoRA2/20。B1救回0、退化1；旧LoRA救回2、退化2，平均数相同并不意味着失败集合相同。新96000模型结果尚未产生。

## 已有方法与创新门槛

物体中心片段的空间变换和轨迹重组已有MimicGen先例；本轮A3属于这一类标准几何策略的特权诊断，不能直接成为新的T-RO创新。[MimicGen原论文](https://proceedings.mlr.press/v229/mandlekar23a/mandlekar23a.pdf)

RoboTAP使用点跟踪和视觉伺服复现动作，说明RGB视觉伺服是必须面对的既有方法族；其公开实现描述为4D控制，不能未经实测就宣称已经解决本任务的完整6D要求。[官方项目](https://robotap.github.io/)

ReKep将3D关键点时空关系交由优化器形成SE(3)动作，但使用RGB-D，其信息条件与本轮固定RGB不同；不能直接把其结果当成公平基线，也不能把“空间＋时序约束”概念当作空白创新。[原论文](https://arxiv.org/abs/2409.01652)

目前没有完成同信息RGB物体配准、视觉伺服或接触意图解码强基线的排除实验。若增强LoRA仍失败，也只能说明这一受限配置不足，不能越过这些门槛宣称必须新网络。最终决定等待全部100次固定评测到齐后更新，过程中不追加新网络或调参。
