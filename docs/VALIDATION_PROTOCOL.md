# Validation v1 protocol (fixed before v1 evaluation)

v0 frozen at e8df57930c7d92af0c2f854f555eec6b09860580; original code/configuration retained verbatim.
Evidence tier: PROXY_ONLY. Decision defaults to INSUFFICIENT_EVIDENCE unless the original physical prerequisites in PRE_REGISTERED_GATES.md are satisfied. No learning or physical control.

Seeds: development 314159; independent evaluation 271828, 161803, 141421. Nine scenes per seed, three per family; no rejection sampling or removal of unreachable scenes. Families: asymmetric rectangular grasp, cluttered grasp, grasp and oriented placement. Random object x=[.32,.74], y=[-.22,.22], yaw=[-pi,pi], half dimensions [.035,.022,.035], tabletop z=0. Box obstacles sampled independently at offsets [.07,.18], heights [.08,.30]. Object asymmetric marker means placement yaw fixed; only opposite parallel-jaw grasps are equivalent. No arbitrary 8-yaw equivalence claim.

Eight shared candidate operations: two antipodal grasps times four transit routes (straight, +/- .12 m lateral, high clearance). Same object pose and oriented-placement goal for both robots. Candidate contact physics not validated. Task path starts at a shared pregrasp, descends to contact, lifts, transits, places and retreats for placement family; grasp families finish after lift. Initial movement from robot parking pose is outside the scoped path and explicitly not certified.

2x2 factorial: official SR5/Panda chains crossed with two assumed optical mounts; identical proxy TCP and two-finger hand to isolate arm effects. Camera-only primary factor uses desired Cartesian poses and obstacle/hand occlusion, independent of IK. Actual FK views additionally recorded where IK exists. A body difference is assessed with mount held fixed; mount effects with body held fixed. Interaction is difference-in-differences on geometric conjunction, not proof of nonseparable dynamics.

Numerical IK: <=3 mm / .04 rad, bounded joint limits, deterministic warm start plus one fixed alternative per waypoint. Failed search is UNKNOWN_REACHABILITY, not proof no IK exists. Joint interpolation <=.04 rad per joint; Cartesian path sampled <=.025 m, interpolated tracking checked throughout. Dense finite checking does not certify continuous collision freedom. Robot centerline balls/capsules and hand boxes are explicit assumed collision proxies, not official mesh envelopes. Include table, obstacles, nonlocal self collisions, hand, carried-object obstacle checks. Target allowed contact at grasp/place; no contact dynamics.

Visibility: uniform 5x5 top-surface samples, fraction in frustum/depth and unoccluded by environment, hand and robot proxy. This is visible sample fraction, not exact projected area. Require >=.60 only during approach above .20 m (known near-depth blind region excluded a priori); report contact visibility separately. Camera intrinsics and both mounts are assumptions. Not a calibrated D435i performance test.

Baselines use precisely the same precomputed records and all eight candidates: IK-only; IK+collision; visibility-only; scalar weighted .5 feasibility+.5 visibility; analytic conjunction; geometric shortest admissible path; same-information finite-candidate MPC (exact enumeration, full scoped horizon). Exhaustive enumeration is stronger than stochastic CEM on this finite set. All receive the same maximum eight-candidate evaluation budget; filtering intentionally uses subsets of features. All labels are geometric proxy diagnostics. Analytic AND selection checked with the same label is tautological and is reported as coverage/consistency only. No independent task success endpoint exists.

Statistics: report every scene/candidate and failure; held-out only, scene-cluster bootstrap 2000 resamples with fixed seed 4242; candidate rows never treated as independent replicates. Report per-family/per-seed rates, paired source-valid/target-invalid counts, and exact binomial discordance test as exploratory (no multiple-comparison claim). No parameter/seed changes based on scores. Development split not used for scientific estimates. No training stage unless independent physical outcomes and strong planning comparisons justify it.
