# 下一阶段决定

**当前门槛未通过：INSUFFICIENT_EVIDENCE。暂不进入 COFT 神经网络或 VLA 训练，不提出既定的新学习架构。**

允许继续的是证据补齐与假设收窄，不能把代理实验升级为 T-RO 立项通过。

| 顺序 | 应完成的证据 | 通过标准／分支决定 |
|---|---|---|
| 1 | 核对 SR5 实机型号、关节零位、控制器限制；用不含运动指令的公开／离线参考 FK 或人工提供的姿态测量核对链；补齐两夹爪 CAD、TCP、相机支架与 D435i intrinsics/hand-eye 的测量不确定性 | 所有参数有来源和误差，不能仅修改 JSON 的 status。无这些条件，保持证据不足 |
| 2 | 将相同场景与候选冻结，使用官方外形和经核对夹爪进行完整碰撞／自碰撞；可认证的扫掠碰撞或分辨率收敛；多 IK 分支／冗余搜索，避免将局部求解失败当不存在轨迹 | 区分模型差异、求解器差异、离散误差。扩大几何搜索若解决问题，继续工程实现，停止“需要新学习”的论证 |
| 3 | 离线校验后另行授权真实运行；独立记录对象最终位姿、掉落、接触和视觉估计误差，不由 F/V 标签生成成功结果；初始到预抓取、接触到释放、闭环恢复均进入评价 | 不提前发实体运动命令；本轮不包含这个阶段。使用相同独立场景、全部失败和盲判终点 |
| 4 | 按等信息、等候选、等计算资源，对比几何约束规划和真正接收新观测的 receding-horizon MPC／CEM；增加规划预算、标定误差敏感性和不确定性状态估计强对照 | 若差距被常规方法消除，选 A/B，停止当前学习创新分支；若稳定存在且能定位非几何机制，才讨论 C |

需要调整的核心假设是：从“机器人不同，因此需要联合学习”改为“在明确任务分布和测量不确定性下，相同意图的可执行／可观测集合如何变化；几何方法还有什么可重复的独立任务残差”。这不是改变本轮场景去追求优势，而是下一轮预注册前的研究问题修正。

若日后仅发现静态遮挡，直接使用解析约束与规划。若发现有历史依赖、未建模接触或真实传感误差，也必须先检验状态估计、鲁棒规划、信息增益规划等标准方法；这些现象不自动要求学习。当前无法指定 COFT 不可替代的技术贡献。

立项意见：**保留跨具身几何／观测机制的验证研究，暂缓 T-RO 学习算法立项；停止仅凭 v0 的 100% 代理分数扩展网络的路线。** 这是分阶段决策，不是否定整个跨具身研究方向。
