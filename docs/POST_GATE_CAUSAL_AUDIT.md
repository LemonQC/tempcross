## 2. 16/40→1/40究竟是什么差异

重新配对40个原始索引，得到：源成功/目标失败 **16** 例，目标成功/源失败 **1** 例（95），共同成功 **0**，共同失败 **23**。因此净差15不是“15个同条件源成功、目标失败”。完整索引见[配对JSON](../evidence/post_gate/original_joint_pairing.json)。

对这40对保存初态重新核查，物体资产和任务指令40/40一致，水槽位置差0；目标物体位置最大差约61.02微米，初始相机位姿矩阵最大逐元素差约4.053e-8。因此，**没有证据把这批落差解释为初始相机外参换了或物体资产不同**。仍会随具身改变的包括机器人在图像中的外观/遮挡、初始关节状态、臂运动学与动力学、同一OSC命令的实际响应。相机外参近同不等于像素观测相同，也不等于已经测量了遮挡。[40对场景记录](../evidence/post_gate/joint40_scene_comparison.csv)

这16个源成功/目标失败中：

- **14例整段未发闭爪命令**：64、68、71、72、73、76、82、87、88、89、93、94、97、99。已重新从全部40条Panda H5的实际第七维核对闭爪事件。
- **2例为放置后未完成退离**：70、75。它们不能统一叫“抓取建立失败”。

前者明确暴露了**执行出来的策略决策差异**，但并未识别其原因：图像分布、任务进度识别、夹爪输出或动作语义均可能参与；不能仅凭“不闭爪”判断“视觉看不到”“低层IK不可达”或“缺少新接触表征”。相同策略权重也不代表其在不同观测上会输出相同动作。

整体16/40对1/40支持**此固定策略—观测—控制系统的具身相关性能差异**，不支持把视觉、学习解码器、低层运动学/动力学分别作为已识别的因果来源。Panda95成功、P3特权抓持及已有B1救回也反驳了“目标机器人普遍不能完成该任务”的强说法。

本组UR5eOmron和PandaOmron都使用原Robotiq85夹爪，变化主要涉及机械臂及其执行/视觉外观；当前证据不含新手型或不同接触拓扑的独立变化。相同夹爪仍可能因腕姿、路径及臂响应不同而产生不同接触结果，但不能把本数据直接包装为跨灵巧手接触形态的验证。

## 3. M1的4/5支持什么，为什么不是已完成的视觉方法

固定8例原始Panda没有新定义下的有效双指接触或稳定抬升，源8例都有真实稳定抬升；源94用左右指尖，旧指垫代理漏检。[同一定义重新核查](../evidence/post_gate/source_target_and_intervention.csv)

干预组合一次改变了：接近路径、真值锚定的抓取目标、到达与闭爪时序、抬升动作，以及交回BARX时的图像、物体/机器人状态、策略队列和剩余预算。它没有只改变一个“接触状态感知”变量。

五个成功交接为68、71、72、88、93。交接后原始BARX完成前四个中的68、71、72以及93，共 **4/5**；88失败。因此实验证实的是：**存在五个由特权控制实际到达的状态，其中四个允许原BARX继续完成任务。** 这是对“原BARX普遍没有后半程能力”的反证，支持把前缀执行作为重要调查对象。

但4/5条件化于“该纠正前缀已经成功”，还受困难案例选择、特定抓持状态和剩余预算影响；不是随机交接状态上的性能，更不是独立测试性能。总体仍是 **4/8**。M1接管后的网络只收RGB和原指令，**整个M1系统仍使用了仿真真值前缀**；并未实现用RGB自主获得该前缀。

用因果记号表达，已观察的是 `Y(do(prefix = privileged bundle), original BARX, remaining budget)`，并非 `Y(do(contact-estimator = perfect), everything else fixed)`。因而不能由此单独选择“视觉估计器”“新解码器”或“接触意图网络”。

## 5. 64、76、94和M0/M2同分分别说明什么

**64、76：时间截断，尚未到闭爪。** 预抓取160步结束时仍差46.3/29.9mm；最后约一秒仍移动56.5/36.6mm。终止时无所记录的非预期接触，关节余量和局部雅可比不呈明显退化。已证实到达未完成和超时，不是已证实硬件不可达；同样，局部雅可比正常也不是全局可达证明。

**94：接触布尔值不等于负载稳定。** 到达抓取位姿后close阶段16步中有8个双指接触状态，lift阶段100步仅1个；物体最大上升2.203mm，而TCP终止时距抬升目标约1.04mm。[阶段读数](../evidence/post_gate/condition094_contact.csv)证明该固定“位姿＋闭爪＋直线抬升”组合未带起物体。没有接触力/摩擦裕度记录及因子干预，无法唯一归因为摩擦、法向力、接触几何、动作方向、闭合时序或刚体近似。源94持续指尖夹持并成功，说明瞬时源抓取模板不等于完整负载策略；它不是目标硬件不可能的证明。

**M0和M2各2/8：没有观测到本配置中增加真值物体反馈的成功收益。** 它们成功集合相同，为68、88。共同有效抓持的普通控制记录中，开爪前仍有双指接触的帧，其相对附件位置最大变化约0.87–3.23mm、方向约2.23–6.57°，均小于15mm/10°的阶段容差。[附件变化](../evidence/post_gate/attachment_changes.csv)说明这批记录缺少大附件漂移激励；不能由同分否定视觉反馈/MPC在滑移等情形的价值。

实现还有一项细节：M0用固定TCP参考误差判断到达，M2用实际物体误差判断到达，差异不只在逐步控制目标，还包含反馈相关的阶段推进。它们均是普通控制，不是完整MimicGen、KITE或最优MPC的复现或能力上界。

## 6. 证据强度清单

| 已证实 | 有支持但未识别的因果假说 | 目前无证据的强断言 |
| --- | --- | --- |
| 源/目标完整任务差距；14例目标不闭爪 | 具身变化影响了接触建立/任务阶段决策 | 一定是视觉信息不足或相机外参变化造成 |
| 纠正前缀后有4次原策略继续成功 | 合适前缀可修复一部分策略分布外执行 | 只需一个新接触状态估计器，其他因素均已排除 |
| 普通控制时间/命令幅度受限 | 跟踪预算解释部分失败 | 延长时限必成功，或普通控制理论上不能解决 |
| 94短暂接触但未负载抬升 | 接触保持、时序、运动方向存在配合问题 | 唯一原因是摩擦/力不足；必须学习新物理表征 |
| 这批M2未超过M0 | 测试没有充分激励附件漂移 | 真值反馈或视觉MPC普遍无用 |
| 现有受限/移植学习设置表现弱 | 数据利用、训练和执行仍可能不足 | 充分标准适配、所有已发表方法都已被排除 |

**可观测性边界：** 没有做同观测、不同隐含接触状态的配对；没有遮挡、深度或触觉的独立干预；原日志接触标签不是网络实际获得的观测。因此尚不能判定RGB历史＋本体状态是否足够。若两种隐状态给出相同可用观测历史，却要求不同动作，则仅换网络不能可靠区分；但鲁棒动作或信息获取也可能解决，不能进一步宣称整个任务不可解。这是条件性的识别限制，不是已由本数据证明的不可观测性定理。
