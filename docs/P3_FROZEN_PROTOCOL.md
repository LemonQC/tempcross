# P3 冻结协议：接触空间与闭爪时机

本协议在第一次 P3 物理仿真前提交。数值与哈希以 `configs/p3_protocol.json`、`evidence/p3/frozen/source_contact_bank.json`、`independent_conditions_40_59.json` 为准。P0/P1/P2 不重跑、不覆盖。

## 固定案例及源位姿

开发条件严格为 **22、24、26、29、34、35、37、39**，不是独立测试。八条已有 UR5e 成功轨迹全部已找到连续十状态双指接触，并在其后 100 状态内确认连续十状态接触且上升至少 3cm。取第一个满足标准的接触起点，用同步记录的物体及夹爪 site 世界位姿计算 `T_object_tcp = inverse(T_world_object) @ T_world_tcp`。

TCP 为 `gripper0_right_grip_site`。从 body 世界变换和 XML site 局部变换重建，物体/body 四元数为 wxyz。观测的 `eef_quat_site` 为 xyzw，仅作坐标约定核验：传感器缓存会落后仿真子步，允许核验误差 5mm/2°。普通 `eef_quat` 含不同安装坐标，禁止替代 site 姿态。八对源/目标对象资产路径相同，水槽 fixture 对应关系也已核对。

源释放位姿取确认抬升后的第一个开爪动作之前的 TCP 状态；若没有开爪命令，则取最后一次双指接触后一状态，明确记录为接触丢失代理。源条件 29 使用该回退，不能冒称存在显式开爪行为。释放 TCP 在水槽 fixture 坐标系下表达，再变换到 Panda 的同一水槽坐标系。只使用既有成功动作，不搜索新候选位姿。

## 相同分支与三种干预

从旧 Panda B0 状态 40–350 中取 EEF 到物体中心距离最小的状态 `c`，共同分支为 `min(200,max(40,c-16))`。分支索引分别为 **193、120、134、160、200、163、200、163**。每个干预都从官方冻结初态完整重放相同原动作前缀，核对 qpos/qvel、TCP、物体、夹爪、actuator ctrl、求解器 warmstart 和可记录控制器数值状态。分支间及旧轨迹状态误差阈值为 1e-8；不直接设置分支关节或控制器状态。

- **A1 Closure-only**：机械臂和其余维度使用原 B0 完整动作，在 `c` 起强制闭爪 32 步，之后恢复原夹爪命令。
- **A2 Pose-only**：使用下述标准连续 OSC 路径，夹爪保持 B0 的原始二值命令时间序列，按同一绝对动作索引读取。这里固定命令时间序列以隔离变量，不声称它是改变观测后重新规划的视觉策略。
- **A3 Pose+Closure**：机械臂使用与 A2 相同的预定路径；在下降/抓取保持阶段，连续五状态满足位置误差不超过 15mm、姿态误差不超过 10°才闭合。保持至预定释放阶段，再开爪。没有达到容差就不强制闭爪，并记录接近失败。

A2/A3 的世界抓取位姿在共同分支时由物体姿态和源相对位姿锚定，不随夹爪抓住后物体移动而追逐。路径九阶段及步数为：分支 TCP 向上 8cm/30；抓取位姿上方 8cm/45；下降到抓取位姿/45；保持/20；向上抬升 8cm/35；源水槽相对释放位姿上方 12cm/65；下降/35；释放保持/16；向上退离 12cm/35。共 326 步，之后保持退离目标至上限。A2/A3 的位姿路径和阶段时长完全相同，只改变夹爪控制。

不创建新控制器，不改增益、阻尼、物理或碰撞参数。使用原 OSC_POSE 的 delta 输入，将世界误差转换到其真实参考系，位置/旋转误差增益均 0.4，单控制步范数分别限为 12mm、0.12rad，并通过原动作缩放转换。旋转使用 SO(3) 最短路径插值。原动作后五维保留，其中底盘/躯干为零、arm mode 为 -1。旧轨迹提前结束后，原动作六维置零、夹爪保持其末命令、mode 仍为 -1。

每次最多 600 步，官方成功即停止。没有额外的“只记录抓取就结束”：A2/A3 都继续尝试搬运、放入水槽、释放和退离。连续 OSC 控制不等于数学上证明 IK 可达；路径未跟踪时报告误差、碰撞/限位与超时，不把它归咎于网络。最多 8×3=24 次新开发 rollout；不重复 B0，不追加候选或重跑来调参数。

## 诊断与成功

稳定抓持代理为双指接触且物体相对本次初态上升至少 3cm，连续至少十状态。分别记录接近误差、各 waypoint 是否达到 15mm/10°、不期望的机器人/环境接触、距关节限位 0.01 的事件、双指接触、稳定抬升、水平搬运、释放和末端退离。非有限状态是技术失败，不写成任务失败率。成功始终只取官方 `info.is_success.task`，代理不替代它。

原始 qpos/qvel、body/site/TCP、对象、指垫、接触、原始动作和实际动作以及完整视频均保留。所有干预标记 `PRIVILEGED_DIAGNOSTIC_ONLY`，不参与视觉学习方法公平排名。

## 增强预算普通适配

只训练 Joint Reps，从原 XP-900 50k checkpoint 开始，不从旧 6000 样本 LoRA 继续。新序列 seed=20261109，恰好 **96000 个样本位置**，重新读取官方 RLDS，不机械循环旧缓存。目标两个方向各 50 条，共 100 条；源为现有 mg_pnp_lite。保持官方 0.05:1 源/目标权重及按 transition 平衡、源归一化与 VQ、action chunk8、future40/stride8、224px、无图像增强。shuffle buffer10000，AdamW LR2e-5、weight decay0，上游 LoRA rank32/alpha16/dropout0。

本轮显式使用 TFDS 全部 train split（100 目标/1800 源）。P2 上游加载器默认 train[:95%]，实际覆盖不同；因此若改善，只能归因于增强普通适配，不能将预算增加与覆盖增加单独作严格因果区分。对每个实际输入保存原始轨迹指纹、文件来源、帧索引及样本哈希，并把目标指纹映射回现有 HDF5 的 demo 名，报告唯一轨迹及重复帧覆盖。

依次实际验证 batch8、4、2，一个候选成功即停止；每次完成真实 forward/backward/optimizer step，失败保留原日志，probe 参数丢弃。选择 batch 后更新次数固定为 12000/24000/48000，累计恰好 96000。若完整批量训练仍资源失败，保留更新数、样本序列和最小失败证据，不将未完成模型当作零成功。唯一 checkpoint 为规定末步，不按新测试表现选择。仍只相当于官方 768000 样本暴露的 1/8，标记增强预算受限 LoRA。

## 一次独立确认

仅用尚未使用的官方 **40–59**，40 个原始机器人 entry 的 ID、真实 seed、state/model/metadata 哈希在冻结 JSON 中。先完整验证 bundle，再同窗选择 entry/state/XML，不修改 start_seed 代替选窗。

固定五组各20次：Original Joint/UR5e；Original Joint/Panda；固定 B1(.85/.03/8)/Panda；原6000样本 Joint LoRA/Panda；新96000样本 Joint LoRA/Panda。合计100，不增加可选20次特权测试；开发 A3 的效果不冒称独立泛化。每组输出原始逐次官方成功、抓取阶段、完整动作/视频、同条件 rescue/regression，禁止用 40–59 改规则或选 checkpoint。

最终根据 A1/A2/A3 和增强适配结果判断空间/时机/训练不足。即使几何修正有效，也只是已有 IK/OSC、物体中心 retargeting 的因果证据，不自动成为 T-RO 创新；未排除强标准方法前不设计新 COFT 网络。
