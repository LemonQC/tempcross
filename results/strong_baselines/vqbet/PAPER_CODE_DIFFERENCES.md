# 论文与固定官方代码的差异

本实验以[作者发布代码](https://github.com/jayLEE0301/vq_bet_official/tree/09d4851288ca5deaaa1ab367a208e520f8ee9a84)为实现依据，属于明确标记的RGB/语言/canonical动作移植。不能把“使用作者代码”扩写为“逐项复现论文原生实验”。

| 项目 | 论文/作者代码 | 本轮固定选择及边界 |
|---|---|---|
| 动作序列长度 | [论文附录C.1](https://arxiv.org/html/2403.03181v2)的UR3列为10；固定源码examples/configs/train_ur3_goalcond.yaml为1。论文也有长度1的其他实验。 | 采用已冻结的官方发布配置长度1，每步闭环预测；不声称论文UR3长度10实验复现。 |
| 条件输入 | 原生条件实验使用目标状态/图像序列。 | 一个冻结CLIP语言向量经可学习线性投影作为条件前缀；没有未来目标图像或真值状态。 |
| 视觉 | 论文图像仿真使用ResNet18；官方README支持预提取特征模式。 | 官方冻结ImageNet ResNet18模式，保留源码预处理；不是视觉编码器微调或论文实机HPR表征。 |
| 码权重 | 论文UR3列主次比为0.1。发布源码主码权重5、次码权重0.5。 | 原样保留源码，比例0.5/5=0.1；不能把secondary_code_multiplier=0.5误读成相对主码0.5。 |
| 模型尺寸 | 官方UR3模板六层、六头、120维GPT，512维RVQ、两组16码。 | 保留这些原生参数以及残差码解码和连续偏移，不用连续回归替代量化模块。 |
| 计算预算 | 原生数据集以epoch和大batch配置。 | 每设置RVQ6000/BeT24000真实更新、目标batch64/16，源目标1:1；不声称论文等计算预算。 |
| 数值精度 | 原生代码继承PyTorch cuDNN默认设置。 | 唯一技术修复统一关闭TF32，旧探针和smoke保留；算法和动作定义未变。 |

这份文献差异说明在正式训练完成、reference评测已经开始后补充。它只补充可核查的实现边界，不改变已提交的冻结配置、训练预算、checkpoint选择或动作接口，也不据reference表现发起另一个配置。
